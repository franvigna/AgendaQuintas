# Reglas del proyecto

## Commits

- Mensaje corto y puntual: una sola línea que diga qué se hizo (ej. "Ajustes visuales").
- Nunca agregar coautor (`Co-Authored-By`) ni ninguna atribución a Claude, ni en commits ni en pull requests.
- Sin cuerpo en el mensaje, salvo que el usuario lo pida.
- Flujo habitual cuando el usuario pide subir cambios: `git add .`, `git commit -m "<mensaje corto>"`, `git push origin main`.
